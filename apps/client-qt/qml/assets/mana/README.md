# Mana symbol font

`mana.ttf` is the unmodified Mana 1.18 font by Andrew Gioia, from
<https://github.com/andrewgioia/mana/tree/6ca9e696d3bda2519dcf3eebd96598f84ad9ddd8/fonts>.
It is bundled under SIL OFL 1.1; see `OFL.txt`. No system font installation or
runtime download is required. Only the symbol font is used, not the upstream
MPlantin/Beleren text fonts or web stylesheets.

SHA-256: `a23809f7c0af7f9866734216bdd73bce2cfedd67333f5cde86a9ee066fa69819`.

All mana, tap, and card type symbol images are copyright Wizards of the Coast
(https://magicthegathering.com), as stated in the upstream README.
