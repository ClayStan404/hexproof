# Hexproof 3.3.0

## English

- **Duel Commander AI practice.** Optional native Forge AI now supports one
  human against one AI in two-player Duel Commander BO1. Choose the AI deck
  separately in the waiting room. Both decks follow the existing Duel Commander
  100-card, singleton, color-identity and catalog legality checks. Each player
  starts at 20 life with their own one or two designated commanders, command
  zone and independent per-commander tax. Easy, Normal and Hard are practice
  presets, not certified ratings; difficulty does not change decks or shuffles.
  This does not add AI to multiplayer Commander/EDH, BO3, Limited/Cube or
  tournaments. The upstream AI can use information inside the trusted engine
  that a human player cannot see; viewer-specific network privacy does not
  certify player-view fairness of the AI.
- **An in-match keyword reference.** Open a searchable, read-only reference
  from manual or Forge tables without selecting a card. English/Chinese names
  and listed aliases find original bilingual explanations with rule numbers.
  The offline reference covers all 70 named keyword actions and 194 named
  keyword abilities in Comprehensive Rules 701/702 effective September 25,
  2026, including the Infinity symbol heading. It displays the source and
  coverage limits. Ability words, other rule sections, card-specific text and
  future rules revisions are outside that scope; Assemble is listed with its
  source's incomplete-rules warning. Some Chinese names are unofficial lookup
  aids. These summaries do not replace full rules, Oracle text or a judge's
  ruling, and do not enforce rules, inspect hands or submit game/Forge actions.
  Table shortcuts are blocked while the reference is open, and usable focus
  returns when it closes. The reference is unofficial and not endorsed by
  Wizards of the Coast.
- **Maintenance.** Home-node bundles keep verified, hash-linked Forge source
  references instead of redundant complete source archives on each game node;
  matching complete sources remain in the release/source distribution process,
  and existing rollback trees are preserved. Build workflows refresh their
  pinned artifact actions. Development guidance clarifies permission-scoped AI
  assignment, independent review, missed-feedback reconciliation and native
  source-task completion.

**Compatibility and optional services**

- Game connections retain `hexproof.v2`; internal cluster RPC remains
  `hexproof.cluster.v1` and the player-host helper protocol remains 1.
  Application versions may differ when the game protocol matches, including
  ordinary play with 3.1.0/3.2.0 peers. Application-version equality is not an
  admission gate. Legacy 3.0.0/v1 peers still require an upgrade. Installing a
  3.3.0 client alone does not require a compatible hub upgrade; the keyword
  reference is entirely a client feature.
- Enabling Duel AI requires the new client, a hub implementing Duel AI admission
  and the selected Forge runtime advertising both `forge-ai-v1` and
  `forge-duel-ai-v1`. Server hosting and player hosting have separate availability
  flags, which default to unavailable when omitted. Player hosting additionally
  requires the bundled helper and its exact current overlay identity. Cluster
  placement enables Duel AI only after the coordinator explicitly acknowledges
  support during registration. Older coordinators keep ordinary room allocation
  with Duel AI disabled. Older runtimes can retain existing constructed AI while
  rejecting Duel AI. Upgrading a server/runtime/coordinator to enable this
  optional feature is separate from admitting a protocol-compatible client.
- Forge adapter revision stays at 34, but its full runtime content identity has
  changed since 3.2.0. Retain the existing exact runtime/helper identity and
  artifact checks when hosting or executing an engine. Ordinary players and
  spectators do not need a matching local Forge installation. These notes do
  not establish that any server or optional service has been upgraded or enabled.

**Packages and installation**

Client package targets are Windows 10/11 x64 (portable ZIP), macOS 13+ Apple
Silicon/ARM64 (zipped app), and Linux x86_64 (tarball, Ubuntu 24.04 runtime
baseline). Server packages target Linux AMD64 and ARM64. Linux clients still
depend on compatible system C/C++ libraries and graphics/input support. These
are portable archives: exit Hexproof before manually replacing the application;
the updater's verified download does not apply itself. macOS packages may be
ad-hoc signed or lack Apple notarization. Follow the workflow-managed macOS
installation/signing notice attached to the actual release; its first-launch
instructions remain applicable when present.

**Validation limits**

Existing Linux native keyword-reference checks use public manual/Forge table
fixtures. They do not exercise a live Forge-engine match or OS input injection,
and do not establish Windows or Qt 6.5 coverage. Complete verification of the
final frozen 3.3.0 source and packaged-platform qualification are separate release
steps; these source notes do not attest their completion.

## 中文

- **法禁 AI 练习。** 可选的原生 Forge AI 新增法禁（Duel Commander）两人 BO1：一名真人对战一名 AI，可在等待室单独选择 AI 套牌。双方套牌均沿用现有法禁的 100 张、单卡限制、颜色标识及牌库合法性检查。双方各以 20 点生命开始，拥有各自指定的一名或两名指挥官、统帅区及每名指挥官独立计算的指挥官税。简单、普通、困难是练习预设，并非认证等级；难度不改变套牌或洗牌。本次不为多人 Commander/EDH、BO3、限制赛／Cube 或锦标赛增加 AI。上游 AI 可能使用受信任引擎中真人看不到的信息；按观看者隔离的网络隐私不代表 AI 严格遵守真人视角的信息公平性。
- **对战内关键词参考。** 在手动桌或 Forge 对战中，无需选中卡牌即可打开可搜索的只读参考，通过中英文名称及所列别名查找原创双语解释与规则编号。离线内容覆盖 2026 年 9 月 25 日生效的《完整规则》701／702 节中全部 70 个具名关键词动作和 194 个具名关键词异能，包含 Infinity 符号条目，并显示来源与覆盖范围。异能提示、其他规则章节、卡牌专属文字和未来规则修订不在此范围；Assemble 条目保留其来源未提供完整规则的提示。部分中文名称仅为非官方检索辅助。这些摘要不能替代完整规则、Oracle 文字或裁判裁定，不会自动执行规则、读取手牌或提交游戏／Forge 操作。打开时会阻止桌面快捷键，关闭后恢复可用焦点。本参考为非官方内容，未经威世智认可。
- **维护改进。** Home 节点包保留经过校验、由哈希关联的 Forge 源码引用，不再给每个游戏节点重复复制完整源码归档；匹配的完整源码仍通过发布／源码分发流程提供，已有回滚目录保留。构建工作流更新固定版本的产物操作。开发指南进一步明确按权限分配 AI 任务、独立审查、遗漏反馈对账及原生源码任务完成规则。

**兼容性与可选服务**

- 游戏连接继续使用 `hexproof.v2`，集群内部 RPC 继续使用 `hexproof.cluster.v1`，玩家托管辅助组件协议仍为 1。只要游戏协议相同，应用版本可以不同，包括与 3.1.0／3.2.0 客户端或服务器进行普通对战；应用版本号相等不是准入条件。旧版 3.0.0／v1 仍须升级。仅安装 3.3.0 客户端无需升级协议兼容的游戏服务器；关键词参考完全属于客户端功能。
- 启用法禁 AI 需要新版客户端、实现法禁 AI 准入的游戏服务器，以及同时声明 `forge-ai-v1` 和 `forge-duel-ai-v1` 的所选 Forge 运行时。服务器托管与玩家托管分别声明可用性，省略时默认不可用。玩家托管还须使用随包辅助组件及精确匹配的当前 overlay 身份。集群仅在协调器于注册时明确确认支持后，才会启用法禁 AI 分配；旧协调器继续普通房间分配，法禁 AI 保持关闭。旧运行时可以保留已有的构筑 AI，同时明确拒绝法禁 AI。为启用这一可选功能而升级服务器、运行时或协调器，与接纳游戏协议兼容的客户端是两件事。
- Forge adapter 修订仍为 34，但完整运行时内容身份较 3.2.0 已变化。托管或执行引擎时，仍保留现有的精确运行时／辅助组件身份及产物校验；普通玩家和观战者无需在本机安装匹配的 Forge。本说明不代表任何服务器或可选服务已经升级或启用。

**安装包与安装限制**

客户端目标为 Windows 10／11 x64（便携 ZIP）、macOS 13 及以上 Apple Silicon／ARM64（压缩应用），以及 Linux x86_64（tarball，以 Ubuntu 24.04 为运行时基线）；服务器提供 Linux AMD64 和 ARM64 包。Linux 客户端仍依赖兼容的系统 C／C++ 库、图形及输入支持。这些均为便携归档：手动替换应用前须退出 Hexproof，更新器完成校验下载后不会自行应用。macOS 包可能仅为临时签名，或未经过 Apple 公证；请遵循实际发布中由工作流附加的 macOS 安装／签名提示，如有首次启动说明仍须按其操作。

**验证范围限制**

已有 Linux 原生关键词参考检查使用公开的手动桌／Forge 桌面夹具，不覆盖真实 Forge 引擎对局或操作系统输入注入，也不能证明 Windows 或 Qt 6.5 已通过验证。最终冻结的 3.3.0 源码完整验证及各平台安装包资格验证属于后续独立发布步骤；本源码说明不证明这些步骤已经完成。
