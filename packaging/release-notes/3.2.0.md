# Hexproof 3.2.0

## English

- **Easier feedback follow-up.** My feedback refreshes up to five eligible active
  conversations when opened and lets you filter reports awaiting your reply.
  Saved summaries, AI update times and sync status make new questions easier to
  find. Feedback details put AI progress and questions first, keep the original
  submission and receipt in an expandable section, and show newer conversation
  entries first with timestamps. Reply drafts show the question above your answer.
- **Clearer recovery after connection problems.** Feedback explains when it will
  retry automatically, when it needs to check whether an earlier submission was
  received, and when you can refresh saved status. Checking status does not send
  another copy. Unsynced conversations are distinguished from reports awaiting
  assessment, and cached information remains available when refreshing fails.
- **More useful screenshot attachments.** Local screenshot thumbnails can be
  opened before sending. Larger PNG/JPEG source images are accepted within the
  supported limits and, when needed, reduced proportionally to the existing
  upload limit before the public preview. Oversized images now report a size
  error instead of an unsupported-format error. You can attach up to two images.
- **Readable public feedback issues.** New GitHub issues use a short excerpt of
  the submitted description in their title. The body puts the report and
  attachments first, with technical and tracking details folded away. Existing
  issues retain their verification, follow-up closure and removal support.
- **Forge priority choices no longer trap cards underneath.** The Hide choice
  control also covers action lists for cards outside the battlefield, such as
  casting from the graveyard during normal priority. Revealing a covered card
  hides the overlapping list without moving the battlefield or submitting an
  action. The list stays hidden during updates and resizing and returns for the
  next decision.
- **Simpler development and maintenance.** Development, independent review and
  merging now use pull requests in the public repository. Daily checks use focused incremental builds. Releases run the complete local
  suite once for the frozen source; CI packages that qualified source without
  repeating those tests. The feedback service also has a separate attested
  package update path, so it can be maintained independently of game services.

**Compatibility:** This release retains `hexproof.v2` and Forge adapter 34.
Client and game-server application versions may differ when their game protocol
matches, including 3.1.0 and 3.2.0. The existing Forge runtime/helper identity
checks remain in force. The new server-side issue formatting requires an updated
feedback receiver; installing the client alone does not update that service.

Feedback remains public and AI-processed. Closing a development issue after a
reviewed fix merges is separate from publishing a released fix and from your
request to stop follow-up. Review the public preview before submitting.
Packages target Linux x86_64, Windows x64 and macOS ARM64 clients, plus Linux
AMD64/ARM64 servers. Workflow-managed macOS installation/signing notes still
apply. Updating game servers is not required solely to connect a 3.2.0 client
to a compatible 3.1.0 hub.

## 中文

- **反馈跟进更清楚。** 打开“我的反馈”时每轮最多刷新 5 条符合条件的活跃反馈，可筛选“等待你回复”的记录，并查看已保存的处理摘要、AI 更新时间及同步状态。反馈详情优先展示 AI 进度和追问，原始内容与回执可展开查看；对话按最新内容在前显示，并标明时间。回答追问时，问题会显示在输入框上方。
- **网络异常后知道下一步怎么做。** 反馈界面会说明何时自动重试、何时先确认上次提交是否送达，以及何时可以刷新已保存的状态。查询状态不会重复发送反馈。“尚未同步”与“等待评估”分别显示，刷新失败时仍保留已有信息。
- **截图附件更好用。** 添加截图后可直接查看本地缩略图并打开预览。支持在规定范围内选择较大的 PNG/JPEG 图片，需要时会先按比例缩小至现有上传限制，再供你确认公开预览。超出图片限制时会准确提示大小问题，不再笼统显示“不支持此格式”。最多可添加两张图片。
- **公开 Issue 更易读。** 新建 GitHub Issue 的标题会使用反馈正文中截取的简短内容，正文优先展示反馈内容和附件，技术信息与追踪标识折叠展示。已有 Issue 仍保留核验、停止跟进和移除支持。
- **修复 Forge 优先权操作列表遮挡卡牌的问题。** 普通优先权期间，从坟墓场等战场外区域施放卡牌的操作列表也可以通过“隐藏选择”收起。查看被挡住的卡牌时会隐藏重叠列表，不移动战场，也不会误提交游戏操作；列表在状态更新和窗口调整后保持隐藏，到下一个选择时再恢复。
- **开发与维护流程更精简。** 开发、独立审核和合并统一通过公开仓库的 PR 完成；日常开发使用有针对性的增量检查；发版时对固定源码完整验证一次，CI 打包不再重复这些测试。反馈服务也支持使用带来源证明的独立安装包更新，可与游戏服务分别维护。

**兼容性：** 本版本继续使用 `hexproof.v2` 和 Forge adapter 34。只要游戏协议一致，客户端与游戏服务器的应用版本就可以不同，包括 3.1.0 与 3.2.0；Forge 运行时和辅助组件仍保留各自的兼容性检查。新的服务端 Issue 排版需要更新反馈接收服务，仅安装新版客户端不会更新该服务。

反馈内容仍为公开提交，并由 AI 处理。修复合入后关闭开发 Issue、修复正式发版，以及用户主动停止跟进，是不同的状态。提交前请确认公开预览内容。客户端支持 Linux x86_64、Windows x64 和 macOS ARM64，服务端提供 Linux AMD64/ARM64 包；macOS 安装与签名提示仍以发布工作流附加说明为准。3.2.0 客户端连接协议兼容的 3.1.0 游戏服务器，无需仅为版本号升级游戏服务器。
